# Data attribution

No recordings are redistributed in this repository. Download them from the official sources.

## AERPAW (all results)
A. H. Fahim Raouf, S. J. Maeng, O. Ozdemir, I. Guvenc, M. Sichitiu, "AERPAW sub-6 GHz spectrum
monitoring dataset: Fixed nodes CC1, CC2, LW1 (February 2022)," Dryad, 2026.
DOI: [10.5061/dryad.hmgqnk9zn](https://doi.org/10.5061/dryad.hmgqnk9zn). Licence: CC0-1.0.

## NIST (not used)
No NIST data or derived result is in this repository. A NIST spectrum-occupancy release was considered
as a possible second dataset, but its file server was unreachable when tried, so the project uses
AERPAW alone. It is listed here only so the omission is explicit.

D. G. Kuester, X. Lu, D. Gu, et al., "Distributed Sensing of Radio Spectrum Occupancy Amid COVID-19
(Data Release)," NIST, 2022. DOI: [10.18434/mds2-2553](https://doi.org/10.18434/mds2-2553).
