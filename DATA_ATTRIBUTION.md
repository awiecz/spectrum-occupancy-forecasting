# Data attribution

No recordings are redistributed in this repository. Download them from the official sources.

## NIST (planned, not used for results)
The study was planned around this release, but its file server was unreachable for the whole project,
so no results use it. Cited because the original plan drew on it.

D. G. Kuester, X. Lu, D. Gu, et al., "Distributed Sensing of Radio Spectrum Occupancy Amid COVID-19
(Data Release)," NIST, 2022. DOI: [10.18434/mds2-2553](https://doi.org/10.18434/mds2-2553).
Terms: [NIST open licence](https://www.nist.gov/open/license) (attribution requested).
Companion report: NIST TN 2240, DOI [10.6028/NIST.TN.2240](https://doi.org/10.6028/NIST.TN.2240).
Site identifiers are the dataset's own anonymised numbers; this project does not attempt to
localise or identify participants.
